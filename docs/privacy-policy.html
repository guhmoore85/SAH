Privacy Policy — EveryAction Gmail Sync

Last updated: October 2, 2026

EveryAction Gmail Sync is an internal data automation tool built and operated by Stop AAPI Hate. It is not a public-facing application and is not available for installation by the general public.

What this application does

This application periodically connects to a single Stop AAPI Hate-managed Gmail inbox to locate scheduled report emails sent automatically by EveryAction (our CRM/advocacy platform), using a small, fixed set of known email subject lines (e.g. "EveryAction Scheduled Report - Email Comparison Report"). When a matching email is found, the application:

  • Extracts a secure download link for the attached CSV report from the email body
  • Downloads that CSV report
  • Loads the report's contents into a private Google BigQuery dataset used for Stop AAPI Hate's internal analytics and reporting
  • Applies a Gmail label to the processed email so it is not re-processed on the next run

The application does not read, modify, forward, or otherwise access any other email in the inbox. It does not compose or send email. It does not delete any email or attachment.

What data is accessed

This application requests the gmail.modify Google API scope. This scope is used solely to (a) search for and read the specific report emails described above, and (b) apply a Gmail label marking them as processed. No broader mailbox access, message content outside the matched emails, or account settings are accessed.

How data is stored and used

Data extracted from these reports (aggregate email-campaign and fundraising-form performance metrics; no individual constituent/donor personal data is extracted from the report content handled by this specific pipeline) is loaded into a private, access-controlled Google BigQuery dataset owned by Stop AAPI Hate. It is used exclusively for Stop AAPI Hate's internal reporting and dashboards. It is never sold, shared, or disclosed to any third party, and is never used for advertising or any purpose unrelated to Stop AAPI Hate's own internal operations.

Data retention

Report data is retained in Stop AAPI Hate's internal BigQuery dataset for as long as it remains useful for internal historical reporting, and is deleted or overwritten as part of routine data management. Gmail account access can be revoked at any time by the Stop AAPI Hate staff member who authorized it, via Google Account → Security → Third-party access.
